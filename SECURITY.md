# Security Policy

## Scope

This policy covers security issues affecting:

- The LayoutLock macOS application.
- The official LayoutLock website, downloads, and update delivery.
- LayoutLock licensing and entitlement services.

## Supported Versions

Before LayoutLock's first public release, security fixes target the current
default-branch version. After the first public release, only the latest
published version receives security fixes. Users of older versions should
update to the latest release.

## Reporting a Vulnerability

Please do not report security vulnerabilities through a public GitHub issue or
discussion.

When available, use **Report a vulnerability** in the repository's Security
tab. Otherwise, email [support@layoutlock.app](mailto:support@layoutlock.app)
with the subject `Security vulnerability report`.

Include as much of the following as possible:

- The affected LayoutLock version or build.
- Your macOS version, when relevant.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- A proof of concept, screenshots, or logs that help explain the issue.

Remove credentials, license keys, personal information, and unrelated private
data from any supporting material before sending it.

Reports are reviewed on a best-effort basis. We may contact you for more
information and will share progress when practical, but we do not guarantee an
acknowledgement or remediation timeline. Please allow a reasonable opportunity
to investigate and address the issue before public disclosure.

## Responsible Research

Use only accounts, systems, and data that you own or have permission to test.
Avoid privacy violations, data destruction, service disruption, social
engineering, and attacks against third parties. If you encounter data that does
not belong to you, stop testing and report the issue privately.

We appreciate good-faith reports that follow these guidelines.
